# Web-Dev-Learning

Learning workspace for HTML and CSS practice, organized by lectures and small projects. This repository tracks exercises, demos, and mini-projects as I progress through web development topics.

## Repository layout

- `HTML/` - HTML fundamentals and lecture-based practice files.
- `CSS/` - CSS topics, each lecture in its own folder.
- `Projects/` - Small practice projects built from the learned concepts.

## HTML folder

The `HTML/` folder contains topic-based lecture directories and standalone practice files. Typical contents include:

- Basic tags, tables, and lists
- Forms (multiple variations)
- Media elements
- Simple styling and scripts for early lessons

## CSS folder

The `CSS/` folder is organized by lecture number, each covering a focused topic. Examples include:

- Display and position properties
- Flexbox and grid layouts
- Media queries and responsiveness
- Shadows, transitions, transforms, and animations

Some lectures include multiple HTML files to compare approaches or demonstrate variations.

## Projects folder

The `Projects/` folder contains small build-along exercises:

- Card layouts
- Recipe page

Each project includes an `index.html` and a `style.css` file.

## How to view

Open any `index.html` file in a browser to see the lesson or project output. For CSS lessons, the HTML files typically link to a local stylesheet within the same folder.

## Notes

- File and folder names reflect the original lecture naming and are kept as-is.
- This repository is for learning and reference rather than a production-ready app.
